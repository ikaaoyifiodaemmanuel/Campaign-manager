# Campaign Manager - AI Powered Marketing Tool

SIWES Project by Ikaaoyifioda Emmanuel
Department of Maths and Computer Science | To-do-ai | 2026

## Overview
Campaign Manager is an AI-powered tool that helps businesses create, schedule, and track marketing campaigns in one place. Developed during my SIWES program at To-do-ai.

## Key Features
- Create new campaigns with AI-generated content suggestions
- Smart scheduling - AI suggests best time to post
- Campaign to-do list and task tracking
- Performance dashboard for clicks and engagement
- User-friendly interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript (React)
- Backend: Node.js
- Database: MongoDB / Firebase
- AI: OpenAI API
- Version Control: Git & GitHub

## How to Run Locally
1. Clone the repository:
   git clone https://github.com/ikaaoyifiodaemmanuel/campaign-manager.git
2. Go into folder: cd campaign-manager
3. Install dependencies: npm install
4. Start app: npm start
